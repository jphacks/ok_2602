## 製品概要
**NetSim Lab**(以下、本アプリ) は **NetworkSimulator Laboratory** の略で、ネットワークのシミュレーションを勉強・研究するためのアプリであるという意味である。\
ただ単なるネットワークのシミュレーターではなく、このアプリのメイン機能として**ネットワーク機器になりきる**という機能を提供する。\
JPHAKCS2026 Hack Day 終了時点では最小構成で、**ルーターのなりきり機能**を実装しており、
- ルーティングテーブル
- ARPテーブル
- MACアドレステーブル

をもとに

- 宛先MACアドレス
- 送信元MACアドレス
- 宛先IPアドレス
- 送信元IPアドレス

を適切に入力して**パケットを作成・転送する**というのを経験することが可能である。

### 背景(製品開発のきっかけ、課題等）
本アプリが解決・解決に寄与する課題は **ネットワークの理論と現実のギャップを埋めること** である。\
きっかけとして、開発者の1人が、**「プロトコルやヘッダがあるのは分かるし、カプセル化というのも分かる。しかしネットワークの一連の流れが理解しきれない」「ネットワークの一連の流れは分かったが、現実は複雑なネットワークで構成されていて、理論と現実のギャップを埋めきれない」** という悩みを感じた経験がある。

ここから、
- ネットワーク通信の一連の流れを理解できない人がいるのではないか
- ネットワークの理論と現実のギャップを理解できない人がいるのではないか

というところに着目した。

具体的なターゲット層として、
- ネットワークの基本的な知識のインプットで止まっている
- ネットワークの理解度が浅いところで止まっている
- ネットワークの一連の流れ・パケットがどのように動いているのかが分からない

という状況で、かつ、ネットワークのさらなる理解を深めたい人がターゲットである。\
さらなる理解を深めたいとは、ネットワークの流れを理解するということから、ネットワークを脳内でトレースできるようにしたい、プロトコルヘッダを暗記して0の状態からパケットを作れるようになりたいという欲求も含む。こういった欲求に対しても、パケットを自ら構築するというこのアプリだからこそ寄与できるものであると考えている。

### 製品説明（具体的な製品の説明）
### 特長
#### 1. 特長1
本アプリの特に目立った特長として、**ルーターになりきる**ことである。

既存のネットワーク学習に寄与するアプリの多くは、ネットワーク構成図を観察しながらパケットがどのように移動するかを観察するものが多く、俯瞰的な目線からネットワークを観察するものが多かった。\
しかし本アプリはネットワーク機器目線に立つことで別の目線からの理解を提供することができる。

#### 2. 特長2
2つ目に、**パケットを解析・作成**することができることである。

前述したように、既存のネットワーク学習に寄与するアプリの多くはパケットの流れを俯瞰的に観察するため、パケットがどのようにできているかを可視化することが難しい。
しかし本アプリはルーターになりきることでルーティングテーブルやARPテーブル、受信したパケットをもとにパケットを作成し、転送するため、ネットワーク機器がどのようにパケットを解析し、作成するのかを体験的に学ぶことができる。

#### 3. 特長3
3つ目に、ルーターが普段参照しているデータや実行しているパケット解析・作成を、**分かりやすいUI/UXで体験**することができることである。

ネットワークの学習をしていると、始めの頃はルーティングテーブルやARPテーブルを別々に紹介されることも多々あるが、本アプリではそれを統合的に可視化することで概念の繋がりを理解することができる。


#### 4. 特長4
4つ目に、**ステージの難易度(ユーザーに求めるアクション)を調整できる**ことである。

プロトコルヘッダを記入するが、どれをアプリ側で自動で記入し、どれをユーザーに入力させるかをステージごとに変化させることができるように設計されており、アドレスのみを入力させる簡単なステージから、全ヘッダを入力させるほどの高難易度のステージも構築することができる。


### 解決出来ること
本アプリは、ネットワークの学習をしている者を対象にしており、
- ネットワーク通信の一連の流れを理解できない人
- ネットワークの理論と現実のギャップを理解できない人
- ネットワークの基本的な知識のインプットで止まっている
- ネットワークの理解度が浅いところで止まっている
- ネットワークの一連の流れ・パケットがどのように動いているのかが分からない

というような者が想定ターゲット層であり、本アプリでの学習を通してネットワークの理解を深め、より具体的なネットワークの理解をすることが可能である。

さらに、ネットワークの理論を学習している者たちが、その先のネットワーク学習のステップアップやネットワークを活用したプロダクト開発などに繋げることが可能である。

### 今後の展望
本アプリは短い開発期間であったため、深くまでこだわることはできなかったが拡張性をもたせた設計を意識した。
そのため今後の展望としては幅広い機能を追加することを想定しており、元々の課題であるネットワーク学習に繋がるものとして、
- webサーバーやメールサーバー等の追加
- TCPやTLS、アプリケーションプロトコルの実装

というように、プロトコルやネットワーク機器の追加が可能である。\
また、学習を主軸に置いているため、本アプリをホストアプリ化することによって、教育機関やネットワーク研修が必要な企業において、教育担当者が自身のサーバー等でアプリを稼働させ、ネットワーク教育のレベルを上げることにも寄与できる。

さらに、ネットワーク構成とパケット通信を活かすことで、
- ネットワークセキュリティ攻撃/防御の実験
- ネットワークセキュリティ攻撃/防御の可視化

という機能を追加することも可能である。

学習という目的から抜け、探求・研究活動にも活かすことができる可能性もある。
具体的に、
- ネットワーク構成の構築
- 独自プロトコルの実装

というようなことも可能である。

これらの展望を達成できれば、アプリのタイトルである**NetSim Lab (NetworkSimulator Laboratory)**という、ネットワークのシミュレーションのラボのような役割を果たすことができ、ネットワークの発展に寄与することができる。

### 注力したこと（こだわり等）
* **拡張性**: 何度も繰り返すようになるが、今後の展望を見据えた拡張性を設計段階から意識して開発していた。
* **UI/UX**: こちらも何度も繰り返すようになるが、ユーザーの理解の妨げにならないような・理解を促進できるようなUI/UXになるように実際にプレイをしながらの開発を意識した。
